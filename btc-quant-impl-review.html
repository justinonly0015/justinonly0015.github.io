2. 数据流与职责

每日 UTC 00:15(北京 08:15) 定时:
  healthcheck ─→ collect ─→ compute ─→ (verify_report 快照守卫)
                                    │
  主执行机(北京网络): binance.com API 不可达; data-api.binance.vision / gate.io / alternative.me / blockchair / defillama 可达
  E 维: collect 按降级链 binance_fapi → gate_io(healthcheck 预判,失败自动降级)
        另: 用户在其他可达机器跑 fetch_binance_e.py → 拷回 data/raw/<date>/derivatives.json 覆盖 → 重跑 compute
  compute → data/snapshots/<date>/<coin>_snapshot.json + data/history/<coin>_history.jsonl
  harness/build_context → research_input/<date>/ (analyst_prompt + 分维 json + coverage)
  LLM 写 reports/<date>_BTC-ETH_日报.md → verify_report PASS → render_html → pages 发布 + 钉钉卡片

6.2 E2 OI 24h 突变（L1，2026/09/07 启用，决策 17）

chg = oi_today/oi_prev − 1        # prev 取 data/history/oi_<coin>.jsonl 中 date<当日 的最近行
sign = +1 if A3(24h价) ≥ 0 else −1
E2   = clip(chg × 4.0 × sign, ±40)   # score_per_pct=4.0, score_cap=40
语义: 价涨OI涨=健康趋势(正) / 价涨OI跌=空头回补动能弱(负) / 价跌OI涨=空头加仓(负) / 价跌OI跌=去杠杆(正)
无前日值 → E2=0 并 note"OI 序列第 1 天"(决策 17)
实测缺陷 #1（本包新发现，9/8 数据）：E2 未做跨所归一。oi_btc.jsonl：9/5~9/7 source=backfill(snapshot)（gate 口径 ≈$4.5B），9/8 source=binance_fapi（≈$8.4B，币安全市场口径约为 gate 两倍）。E2 直接算 24h 变化 → +88.6% "伪突变" → 因当日价跌 sign=−1 → E2=−40（触 cap），note 显示"OI 24h 88.61%($45亿→$84亿)"。ETH 同理 +119%。跨所口径断层被当作市场突变计入 composite（9/8 BTC composite −13.6 含此失真项）。oi jsonl 的 source 字段已存在但 E2 未消费。修复方向：同源才可比（source 不同 → E2=NO DATA 或需标定系数），正对应 v2.2 的 per-field scope 要求。

6.3 合成与输出

环节规则
A 维聚合dim A = avg(A1,A2,A3,A5,A6)（A4/A7 视数据/修饰）
B / E 维B = avg(B2,B3)；E = avg(E1,E2,E3)（E4/E5 是事件通道不参与均分，见下）
composite仅用 A/B/E 归一加权 20:10:25（实际权重 A=20,B=10,E=25，按可得项重归一）
方向|composite|>30 → 涨/跌，否则横盘；strength=|composite|/30（snapshot 有字段，日报未用）
vol 修饰vol_regime=high(>4%) 时 composite×0.8（A7 定位）
F6F6 单点背景：score=(50−fng)/40×100 裁剪 ±50（fng=69 → −47.5），不进 composite
C 维BTC 链上代理读数(C0_*)仅 readings 背景，不打分；ETH 仅 C6 TVL 单点背景
E4/E5事件通道：liq ≥$500M 记 significant、≥$1B 记 systemic；多头爆仓占比>70% 且 24h 跌>10% → capitulation；均进 e_events 供日报解读，不进 E dim 均分（保 v0.3 E 三指标语义与历史可比）；仅 gate 源提供 liq
coverageof_34（读数可得数，含代理/背景）与 signal_of_34（A/B/E 主信号实际计分指标数）随快照输出；missing[] 声明，LLM 禁虚构
